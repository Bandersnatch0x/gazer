# 0005 — 天气镜像(W1)增补红线 8:明示授权、同源代理、不携设备指纹;参赛版不实现

日期:2026-11-12

## 背景

现行红线 4 只承诺「页面内部 API」。天气调用是**对第三方服务的网络请求**,携带城市级位置,是新的数据边界:v4 规格自己已把「联网只做用户明示授权的聚合服务」列为红线,但红线清单里没有对应条目,规格与红线自相矛盾。

## 被选方案

1. 增补红线 8:环境镜像只收用户**明示授权**的聚合数据;请求走**同源代理**;**永不携带**设备指纹、精确坐标或其他识别面;不授权时静默降级(无天气项,历法照常)。
2. 参赛版不实现天气镜像(见 0004 切片表)。

## 被否方案及落选理由

- **参赛版实现天气、靠运行时授权弹窗**:落选——新数据边界 + 新网络依赖进比赛窗口,验收与隐私审查成本不值得;切片表已移赛后。
- **哈希化位置(不暴露城市名)**:落选——天气服务需按位置返回数据,哈希只是自欺;真正的边界是代理与授权,不是混淆。

## 影响面

- `docs/design/ARCHITECTURE.md` 红线清单(新增第 8 条);`research/gazer-v4-shell` 的 W1 规格补「同源代理」一句;若未来实现,涉及网络层模块与授权 UI,均属赛后。
