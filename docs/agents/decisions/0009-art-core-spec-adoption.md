# 0009 — ART-CORE 四锚点美术规范入库 `docs/design/art/` 并立即落地

日期:2026-11-12

## 背景

GAZER 核心美术规范(ART-CORE-01 单眼 / 02 终端 / 03 黑塔 / 04 CRT 框定)四份 P0 规范在会话外定稿,用户显式指令:「评审规范,然后放在本仓内,使用智能体团队开始落地」。该规范是参赛切片(截至 2026-12-05 交付)的美术权威,不是 0008 所述 v4 赛后路线规格。评审发现 2 处 P0 自相矛盾(ALERT 高光位、终端分辨率)、说话者色逻辑冲突、外部参照名 2 处,均已裁定并套用修订(见 `docs/design/art/README.md` 修订记录 R1–R11)。

## 被选方案

四份规范经修订入库 `docs/design/art/ART-CORE-01..04`(README 承载评审记录与修订索引),作为美术面权威;实现按各文档交付顺序①立刻开工,以本地票(0018 地图 + 0019–0022 子票)承载。P0 裁定(R1 ALERT 高光例外、R3 终端独立 UI 层、R2 G 后绘覆盖 P、R8 说话者色相恒定)按推荐项默认执行,列入待裁批次供用户一句话推翻。

## 被否方案及落选理由

- **按 0008 落 `research/` 分支**:落选——用户显式指令入库本仓并落地;且本规范是参赛切片的现行权威,与 0008 的「v4 赛后路线规格不入 main」对象不同,不构成混代。
- **原文原样入库、修订另记**:落选——外部参照名违反外部名铁律,P0 矛盾若原样入库会被 CI 与实现直接撞上。

## 影响面

- `docs/design/art/`(新增,权威美术规范);`docs/agents/glossary.md`(术语增补);票据 0018–0022;`src/render/`、`src/ui/`、`index.html` 等首批落地改动。
