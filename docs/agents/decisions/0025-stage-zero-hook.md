# 0025 — 认领 §3 方案 (a),把 Stage 0 hook 拉长一倍(GV 衰减表首档 1.0→0.5)

日期: 2026-11-16

## 背景

GAME_REVIEW §3 指出 GV 单向阀门存在二选一悬案:(a) 承认必然论恐怖、把全程拉长;(b) 给真实刹车。已落地的调参(tick 3000、stare 减半、stage 衰减)解决了中后段,但 **Stage 0 仍是全权重**:纯鼠标移动下 stare +1.5/3s ≈ +30/min,0→20 GV 只需约 40 秒——玩家还没学会照料动词,世界已经换了底色。用户 2026-11-16 按推荐项裁决:认领 (a),第一幕要密、不开刹车。

## 被选方案

1. `src/sim/rhythm.ts` 的 `GV_STAGE_DECAY` 首档 1.0→0.5,次档 0.55→0.4(维持严格递减);stage 2–4 不动(0.3/0.18/0.1),保住既有终局节奏锚点。
2. 效果:开场 hook 从约 40 秒拉到约 80 秒;节奏模型复算(1300 ticks,忠实复刻 `tests/game-rhythm.test.ts` 的 simulate())——stage4 到达 25.5 分钟(锚点区间 [18,35] 内)、stage5 43.8 分钟(≤60)、零死亡。
3. 测试锚点同步:`stageDecayFor(0)` 钉值 1→0.5;`gvDeltaFor(stare, NOON, 0)` 1.5→0.75;「终局是开场十分之一」改为「五分之一」(0.1 < 0.5/4)。终局绝对速率不变(0.15/0.225 两处钉值原样)。

## 被否方案及落选理由

- **(b) 离开窗口缓降 GV**:落选——「注视即燃料」是主题公理,刹车动词稀释必然论;留给决策落点关闭此悬案。
- **整表等比缩半 [0.5,0.275,0.15,0.09,0.05]**:落选——改写终局绝对速率,破坏 `toBeCloseTo(0.15/0.225)` 两处既有钉值,改动面更大。
- **只改首档不改次档 [0.5,0.55,…]**:落选——破坏「逐档严格递减」既有断言。

## 影响面

- `src/sim/rhythm.ts`(衰减表)、`tests/game-rhythm.test.ts`(三处钉值)、README 无涉。
- 静默周目与四季参数不受影响(hunger/courtship 与 GV 衰减解耦)。
- 已知边界:Stage 1 与 Stage 0 的衰减差从 0.45 收窄到 0.1,第一、二幕的体感差异变小——这是「开场更慢」的直接代价,终局与中段的节奏锚点未动。
