# 0010 — 投影隐藏线进参赛版:规格落 `research/gazer-projection`,与 ART-CORE/FX-LIB 对齐

日期:2026-11-13

## 背景

用户裁定:时间充足(推翻 0004 的窗口担忧,不推翻切片纪律本身);SwarSight 为用户自有项目(许可无碍,仍按外部名铁律自研措辞、零依赖移植);保留当前叙事主线,世界投影作为隐藏线加入参赛版。设计前,ART-CORE 四锚点(0009)与 FX-LIB-MASTER 已落库,规格须与其对齐。

## 被选方案

采纳投影隐藏线 MVP 进参赛版,规格全文落 `research/gazer-projection/SPEC.md`(0008 先例):

- 五层机制:信种(离线快照数据表,纯函数选取)→ 渗入(既有记忆管道,零新规则)→ 倒影(纯聚合,基于 0006 的 SwarmBelief 聚类基座)→ 预测(蜂/蚁信念引擎,自研 TS 零依赖,思想移植自 SwarSight 调度)→ 玩家面(OSD 信道 + 喂假畸变 + 双向尾声)。
- 产品分寸:观察 + 推演,不承诺点预测;全部强度 ≤0.5,零自动播放。
- 载体裁定:倒影信道 = OSD 层(ART-CORE-04 §2.3 语言),不进 panels.ts、不进世界画布;开关复用 ART-CORE-02 §3.1 的伪按钮 `[ _ ]`(GV 80 起首次响应)。
- 零网络、零新增 LLM 调用(红线 8 无接触;600-token 预算不动)。
- 校准验收设量化下限(≥ 随机基线 +10pp),达不到则砍预测层、缩为纯观察——降级路径写死。

## 被否方案及落选理由

- **在线数据接入(天气镜像形态)**:落选——0005 红线 8 与 0004 均已裁过同量级问题;离线快照同构于 ART-CORE-04 内存蠕变的现实日耦合,合规且可复现。
- **倒影走 panels.ts 面板**:落选——panels 是世界 UI;倒影是「显示器自己的功能」,走 OSD 层才与 BIOS 暗线(世界=机器外设)同源。
- **/player 节点做成群体信念**:落选——倒影是引擎聚合不是生物知识;「群体不知道全景」须保持,否则破坏本体论严格性。

## 影响面

- `research/gazer-projection` 分支(SPEC.md);参赛切片票据(T1–T5,见 SPEC §11)按票据路由开本地票。
- 术语增补(外部/信种/渗入/倒影/命中)待并入 `docs/agents/glossary.md`(该文件有并行未提交改动,并入时按行合并,不整文件覆盖)。
- 不改 `docs/design/`(v3 冻结)与 ART-CORE/FX-LIB 任何既有验收。
