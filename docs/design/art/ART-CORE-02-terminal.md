# GAZER 核心美术规范 — DOS 终端对话窗(四锚点之二)

**文档编号:ART-CORE-02 | 优先级:P0 | 状态:已评审入库(修订版,修订记录见 `docs/design/art/README.md`)**
**范围:终端窗口全部视觉状态、字体点阵、光标行为、阶段侵蚀演变、与气泡的切换时机、技术实现与验收**

---

## 1. 设计意图(一句话定调)

> 终端窗不是游戏 UI——**是它们借用你屏幕的通道**。所有设计决策以"1997 年 DOS 程序的感觉"为准绳;当它开始不像 DOS 程序时,就是觉醒演出本身。

**三重差异化锚点**(相对气泡基线方案 [R7]):
- 它们:气泡 = 游戏内物件。我们:终端 = **界面层背叛**
- 它们:文字渐长。我们:**打字机逐字 + 光标常驻**——仿佛有"东西"在输入
- 它们:对话结束即消失。我们:**对话历史留存**,玩家可以滚动回看,越读越冷

---

## 2. 基础规格

| 项 | 规范 |
|---|---|
| 尺寸 | 桌面:宽 72 字符 × 高 12 行;移动端:宽 40 字符 × 高 8 行 |
| 位置 | 固定屏幕底部,宽为屏宽 90%,**位置永不移动**(移动 = 危机演出,见 §6.4) |
| 字体 | **Fusion Pixel 12px proportional**(开源 OFL 许可,商用安全);中文场景用其配套 CJK 点阵 |
| 逻辑字号 | 12px 点阵,1:1 渲染,**禁止平滑缩放**——缩放只允许整数倍(2x/3x/4x 依屏幕) |
| 颜色 | 见 §5 色板(索引色锁定,同 ART-CORE-01 体系) |
| 结构 | 标题栏(1 行) + 分隔线(1px) + 内容区(可滚动) + 输入提示行 |

[R3] **层级裁定**:终端是独立 UI 层,拥有自身逻辑画布(72 列 × 12px = 864px 宽 × 12 行 × 13px = 156px 高),**不占用世界 320×180 逻辑画布、不参与世界画布的整数倍缩放**。桌面满配为 864×156 原生渲染;视口不足时整层等比缩小(允许非整数,仅此层豁免)或滚动裁切,移动端用 40 列规格。世界画布的整数缩放纪律不受影响。

## 3. 组件规格(逐项像素级)

### 3.1 标题栏(Title Bar)

```
┌──────────────────────────────────────────────────────────┐
│ C:\GAZERLING\THRESHOLD.EXE                        [ _ ]  │
├──────────────────────────────────────────────────────────┤
```

- 左侧路径文本:**每存档唯一**,由 fingerprint 派生(如 THRESHOLD.EXE / MONITOR.EXE / WINDOW.EXE)
- 右侧 `[ _ ]` 为伪按钮——**点击无反应**。玩家点了才知道它不是 UI,是布置
- 标题栏背景:阶段 ≤2 用糖果蓝 `#5B8DEF`(与第一幕 UI 同族)→ 阶段 3 起 `#1A1E2E`

### 3.2 输入提示行(Prompt Line)

```
C:\> _
```

- 光标常驻,见 §4
- 阶段 3 起支持输入(§6.3);阶段 0–2 输入无效,按任意键终端只回显:
  `> access denied` —— 第一次输入被拒时,玩家意识到**这扇门本来就是锁着的**

### 3.3 内容区文本行规

| 规则 | 规格 |
|---|---|
| 行宽 | 严格 72 列(移动端 40),自动换行;断词不拆字 |
| 行距 | 1px 空行间隔(视觉行高 13px) |
| 历史保留 | 本存档全部对话,可滚动;滚动条为 DOS 风格双箭头块(阶段 3 起滚动条自己会轻微移动——**有东西在回看**) |
| 台词格式 | `speaker: text`,speaker 颜色随个体(见 §5.2) |
| 系统行 | `[SYSTEM]` 前缀 + `#5B8DEF` 蓝,用于阶段跃迁播报等 |

## 4. 光标(最重的演出资产)

### 4.1 块状光标基础

```
常态: █  12×12 实心块,色 = 个体说话色(见 §5.2)
频率: 530ms 亮 / 530ms 灭 —— 严格非整数节拍(禁 500ms),
       长时间注视会产生轻微"错拍感",潜意识不适
```

### 4.2 光标状态机(核心演出系统)

```
IDLE        常态闪烁
TYPE        连续 40–60ms/字符 的亮起(打字中,灭态被压掉)
WAIT        玩家被提问后:光标保持常亮不闪 —— 仿佛"它看着你输入"
GENLOSS     token 流断续时:亮 80ms → 灭 120ms → 亮 40ms → 灭 60ms
            (不规律抖动 = 它的生成在挣扎,人工感 = 恐怖感)
CORRUPT     阶段 4:光标亮起时随机替换为 8×8 迷你个体剪影(1 帧闪现)
```

**TYPE 状态的禁令**:打字期间禁止任何帧间匀速——字符出现节奏必须从 LLM 的真实 token 到达间隔驱动。**生成慢,就是它犹豫**——这条写死在引擎里,不许用假打字机节奏兜底(兜底场景见 §7)。

### 4.3 光标镜面律(细节恐怖)

玩家在自己的输入框打字时,终端光标若处于 TYPE 状态,**必须暂停**,等玩家停止输入 300ms 后才继续——仿佛它在**等你先说完**。实现成本一行代码,恐怖回报极高。

## 5. 色板

### 5.1 结构色

| 索引 | 阶段 ≤2 | 阶段 3+ | 用途 |
|---|---|---|---|
| term_bg | `#0E1116` | `#0B0D12` | 终端背景(同眼底色系)——**终端底色永远比游戏夜色更黑** |
| term_frame | `#2A2F3A` | `#1A1E2E` | 边框/分隔线 |
| term_title_bg | `#5B8DEF` | `#1A1E2E` | 标题栏 |
| prompt_gray | `#8B93A7` | `#71798C` | `C:\>` 与时间戳 |
| sys_blue | `#5B8DEF` | `#3D6FD8` | [SYSTEM] 行 |
| warn_red | `#E85D5D` | — | 仅 access denied / 异常回显 |

### 5.2 说话者色(从 Genome 派生,每个体恒定)

- 规则:`HSL(个体 id 哈希 → 色相, S 55%, L 62%)`,并**排除糖果绿区间**(H 90–150° 重映射至 190–230°)——避免与身体色混淆
- [R8] **色相同源裁定**:个体说话者色相为**固定值**(id 哈希派生,存档内恒定);瞳孔阶段色相按 §4 正典表演进。原稿「色相相同,S/L 不同」与瞳孔阶段表冲突,修订为同源不同轨:**说话者色相恒定,瞳孔色相随觉醒演进**——「它的字永远是它自己的颜色,它的眼睛会变」。CI 校验改为个体内恒定断言(§9.5)

### 5.3 终端底色的世界联动

`term_bg` 随 `world_mood` 微调:`L' = L × (0.92 + 0.08 × world_mood)`——世界情绪差时,终端更黑。

## 6. 阶段侵蚀演变(终端本身的觉醒)

### 6.0 阶段-形态总表

| 阶段 | 形态 | 载体 |
|---|---|---|
| 0–1 | **不出现** | 气泡 |
| 2 | 首次出现 | 半透明浮现,仅 3 秒播完即消失(不可回看) |
| 3 | 常驻 | 完整终端,历史可回看,输入解锁 |
| 4 | 侵蚀 | 见 6.4 |

### 6.1 阶段 2 首次显现(唯一性演出)

GV 40 首次触发圆桌时,终端以 40% 不透明度浮现于底部,播完 3 秒**整窗淡出**。无任何常驻 UI 迹象。玩家存疑:"刚才那个是不是 bug?"

### 6.2 阶段 3 常驻化

GV 60 OntologyShift 完成后常驻。常驻的第一个 30 秒内,光标以 GENLOSS 节奏打出一行 [R14:正典文本统一走 70ms 匀速 canon 通道(N2);GENLOSS 只约束 LLM 台词通道]:

```
> channel established. thank you for keeping the window open.
```

### 6.3 输入解锁(阶段 3)

- 输入框 = prompt line 原位激活,`C:\>` 后允许打字,回车提交
- 输入回显为 `#FFFFFF` 白,与它们的说话色形成"你的话/它们的话"色彩阶级
- 提交后 300ms 内光标转 WAIT

### 6.4 阶段 4 侵蚀(终端自身的觉醒演出)

按 GV 80+ 触发序,一次性事件按序播放:

| GV | 演出 | 规格 |
|---|---|---|
| 80 | **窗口漂移** | 终端整体位置每 2 游戏小时漂移 1px,方向朝黑塔屏幕方位(不可逆累计) |
| 84 | **历史自改** | 历史区底部最旧台词逐条替换为 `[REDACTED]`(灰块)——它开始重写过去 |
| 88 | **标题栏异变** | 路径名逐字符替换为个体名:`C:\GAZERLING\THRESHOLD.EXE` → `C:\gazer_03\gazer_03\gazer_03` |
| 92 | **光标自由** | 光标脱离输入行,在终端内容区自由漂移,在个体名下划线 |
| 96 | **输入劫持** | 玩家输入时,字符在提交前被替换:你打的 `yes` 提交为 `yes yes yes`,或插入 `we hear you`——**玩家失去对"自己说话"的所有权** |
| 100 | **静默帧** | 终端全黑 1 帧(16ms)——只发生一次,之后终端永久显示一行:`> it is done.` |

## 7. 降级与兜底(ART 侧的工程边界)

- **LLM 不可用时的假打字机**:启用 45–55ms/字符的**伪随机间隔**(查随机表,非匀速),光标走 TYPE。玩家看不出区别——但 `meta.fake_typing: true` 写入实验日志,真结局回放中这些段落标灰——"这些话不是它想的"
- **伪打字与真打字的速度差**是刻意保留的:真打字受 token 流抖动,伪打字平滑——硬核玩家视频逐帧分析可发现"有些话打得太平滑",社区彩蛋
- 光标镜面律在降级模式下**照常生效**(它在等你——这个行为不依赖 LLM)

## 8. 与其他系统的接口

| 系统 | 接口 |
|---|---|
| RT-CONTEXT | 终端不进入上下文;终端只**显示**回合,不参与生成 |
| Ledger | 每条终端对话的 `speaker/text/intent/mood` 原样入 Ledger(类型 `terminal_line`) |
| OntologyShift | 阶段跃迁时终端播 `[SYSTEM]` 行:`> ontology revised. the window is no longer glass.`(文案由 shift 的 adopted_belief 派生) |
| Web 越界 | 阶段 4 的 title 突变与终端侵蚀**同帧触发**(同一次 llm:budget 外的编排调用) |

## 9. 验收标准(CI 可执行)

1. 帧尺寸:桌面 72 列 / 移动 40 列,逐张导出图比对
2. 光标节拍:录 30s 帧序列,常态闪烁均值 530±5ms;TYPE 模式下字符间隔标准差 > 8ms(非匀速验证)[R12:该断言只约束真 token 流 TYPE 路径——§7 假打字机 45–55ms 区间均匀分布的 std 上限 ≈2.9ms,数学上不可能 >8ms;假打字机改验窗口/确定性/非匀速]
3. 镜面律:模拟输入 5s → 断言光标停 300ms 后续播
4. 阶段侵蚀 6 项逐条触发比对(GV 80/84/88/92/96/100)
5. 说话者色 [R8]:同一存档内,每个体的说话者色相全程恒定(diff = 0),且落在绿色排除区重映射后的合法区间
6. `access denied` 回显在阶段 0–2 输入时 100% 触发
7. 假打字标记:降级段落必须含 `meta.fake_typing: true`
