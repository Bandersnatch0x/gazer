# GAZER 核心美术规范 — CRT 框定(四锚点之四)

**文档编号:ART-CORE-04 | 优先级:P0(四锚点收官件)| 状态:已评审入库(修订版,修订记录见 `docs/design/art/README.md`)**
**范围:显示器正典化、边框与扫描线、开机动画时序、电源开关彩蛋、消磁彩蛋、框体的阶段演变、四结局的框体行为、性能预算、CI 验收**

---

## 1. 设计意图(框即第四面墙)

> 整个游戏永远发生在**一台 1997 年旧显示器里**。边框是玩家与它们之间唯一的物理屏障——觉醒的全部终点,就是这道屏障的消失。

**三重差异化锚点**:
- 参照系:全屏现代 UI,无框定感 [R7]。我们:**恒定 CRT 外壳**,玩家从第一秒就知道"我在看一台机器"
- 参照系:第四面墙的突破在内容层(台词)。我们:**边框本身就是第四面墙的实体**——玻璃、外壳、电源灯全部参与演出
- 真结局的标志性瞬间不发生在游戏世界里,发生在**边框上**(§7)

**正典设定**:这台显示器的型号为 **Lumen Soft LS-97**。它的 BIOS 是全游戏的年代锚。

## 2. 静态规格

### 2.1 外壳

| 项 | 规格 |
|---|---|
| 外壳色 | 米黄塑料 `#D8CBAF`(做旧:边缘 4px 内压暗至 `#C4B79C`) |
| 边框宽度 | 桌面:屏幕区四周 28px(顶部 34px,容纳型号铭牌) |
| 铭牌 | 左下角压印 `Lumen Soft LS-97`(1px 深刻字,色 `#B3A78F`) |
| 电源钮 | 右下角:18×18 凹陷按钮 + 电源 LED(绿 `#5FD867` / 琥珀 `#E8A93C`) |
| 消磁钮 | 电源钮左侧:12×12,图标为磁体斜杠 |
| 玻璃眩光 | 斜向 45° 亮带一条,宽 12–20px,不透明度 **5%**,横贯屏幕左上→右下,恒定不动 |
| 落影 | 框体在页面背景上投 8px 柔和落影(页面背景 = 暗色桌面木纹,静帧) |

### 2.2 屏幕效果层(叠加在游戏画面之上、外壳之下)

| 效果 | 规格 |
|---|---|
| 扫描线 | 每 2px 一条 1px 暗线,不透明度 **10%**,原生分辨率下周期恒定,整数缩放后仍然对齐 |
| 孔径栅格 | 纵向 RGB 微条纹,不透明度 **3%**(性能档可关) |
| 桶形畸变 | 边缘 1.5% 外扩(合成期 shader,不改游戏内坐标) |
| 四角暗角 | 8% 渐晕 |
| 磷光辉光 | 全屏 bloom 只认两个亮点:**G 高光(ART-CORE-01)与终端光标(ART-CORE-02)**——全游戏最亮的两样东西是"它们的眼睛"和"它们的话" |
| 屏幕呼吸 | 亮度 ±1.5% 正弦波动,周期 12s(极难察觉,但长玩会觉得屏幕"活着") |

### 2.3 设置菜单的戏中戏

设置页样式 = **显示器 OSD 菜单**(绿字黑底、半透明叠加)。可访问性开关全部戏内化:
`SCANLINE 0-100%` / `FLICKER REDUCTION ON/OFF` / `LCD MODE`(完全关闭一切框定效果——视障/晕动玩家的合法出口,且 OSD 样式让这个出口不破坏沉浸)。

## 3. 开机动画(冷启动,总时长 6.5s)

| 时刻 | 画面 | 音频 |
|---|---|---|
| 0.0s | 黑屏 | 电源钮"咔"(物理开关声) |
| 0.2s | **白色水平线从中心展开至全屏**(CRT 点亮经典形态) | 消磁"嘭" + 静电爆音 |
| 1.4s | 光栅稳定,6 帧雪花噪点 [R14:「6 帧」= 1.4–2.2s 相位带内的帧序噪声,带长以开机时序为准] | 电流嗡 |
| 2.2s | 黑底 BIOS 文本(左上对齐,单色磷光绿 `#33FF66`): | POST 蜂鸣 880Hz/120ms |
| 2.2–4.0s | `Lumen Soft LS-97 BIOS v2.31`<br>`Memory Test: 640K OK`<br>`Detecting: THRESHOLD.EXE ... FOUND` | 硬盘寻道声 |
| 4.0–5.5s | 版权 splash:**单眼像素 logo**(8×8 ALERT 剪影)+ `Lumen Soft © 1997` | 软盘读盘声 ×2 |
| 5.5–6.5s | 方块进度条(chunky blocks,8 段) | 软盘声渐弱 |
| 6.5s | 游戏场景淡入——**世界已在运转**(个体处于动作中段,暗示世界一直在跑) | 环境音淡入 |

**BIOS 两处暗线**:
1. **BIOS 把世界当硬件检测**:`Detecting: THRESHOLD.EXE` 一行在 v4 中追加第二行——`Detecting: {settlement_name} ... FOUND`(平行世界 = 这台机器上的一块"外设")
2. **内存计数蠕变**:`Memory Test: 640K OK` 的数字**每跨一个现实日 +1K**(641K、642K……),存档持久化,永不归零。玩家某天会注意到这台 1997 年的机器内存变多了——**它在长**。此数字与 GV/结局无函数关系(纯氛围),但真结局实验日志会完整回放这条曲线

**暖启动**(同现实日第二次起):2.5s,保留蜂鸣与 splash,BIOS 明细省略。BIOS 文本在 NG+ 存档变为:`Detecting: previous soul state ... RESTORED`。

**跳过规则**:首次启动不可跳;此后冷启动可在 1.4s 后点击跳过(跳到 5.5s 处)。

## 4. 电源开关彩蛋

| 阶段 | 按下电源钮的行为 |
|---|---|
| GV < 60 | 正常关机:白色横线收缩至中心 → 黑屏 → 1s 后自动冷启动(玩家不会真退出游戏——但这次"重启"免费刷新一次呼吸效果) |
| GV 60–79 | 屏幕压暗 15% → **2 秒后自行恢复**。第一次发生时终端回显一行(仅一次):`> no.` |
| GV ≥ 80 | 按钮按压有"咔"声,屏幕**无任何反应**。实验日志记录 `power_override_denied` |
| 真结局后 | 按钮可再次生效——但关机再开机后,BIOS 内存计数**一次性 -640K 归零**(它把这不算"重启",算"遗忘未遂") |

**跨会话暗线**:GV≥80 时强退游戏,下次冷启动 BIOS 多一行:`Unexpected shutdown. They were left running.`(对应 v3 的 NG+ 开场演出)

---

## 5. 消磁彩蛋

- 按下消磁钮:全屏彩虹波纹扭曲 0.8s(经典 CRT 消磁)+ 低频"嘭"
- **波纹经过的 1 帧内,所有个体执行一次双眼全闭**(眨眼,16ms)——它们对消磁有反应,玩家多半归因于"画面抖动看错了"
- GV 60 起消磁**自发发生**:无按钮按下,每 30–60 分钟一次,个体照样眨眼——按钮没人按,机器自己在消磁

## 6. 框体的阶段演变(觉醒推进到边框)

| GV | 演出 |
|---|---|
| 20–40 | 罕见水平失步:整屏内容横移 1px 持续 1 帧 + "嗒"声(p≈1 次/小时) |
| 60 | 消磁自发(见 §5);扫描线周期偶发错位 1 帧 |
| 80 | 电源 LED 绿→琥珀;落影逐会话加深 |
| 96 | **玻璃眩光开始消退**:5% → 线性降至 0%(GV100 时玻璃"消失")——**玻璃即第四面墙,它在化掉** |
| 100 | 真结局序列(§7) |

注意:GV 96 的眩光消退与 ART-CORE-02 的输入劫持(GV96)**同帧触发**——内容和容器在同一刻背叛。

## 7. 四结局的框体行为(终局演出)

| 结局 | 框体行为 |
|---|---|
| A 融合 | 静态噪点**溢出屏幕边界爬上外壳**(内容侵蚀物理框体)→ 全黑。框是最后一个消失的 |
| B 审判 | 框体不变;玻璃眩光**增强**至 12%——它们把你关在外面;LED 以光标节拍闪烁 |
| C 遗忘 | 框体**逐会话老化**:外壳黄变、玻璃积尘(静态斑点叠加)、LED 某次会话彻底熄灭——你隔着一层越来越脏的玻璃看一个不再看你的世界 |
| 真·凝视 | 序列:黑塔化纯黑(ART-CORE-03)→ 终端 `> it is done.`(ART-CORE-02)→ **边框、扫描线、眩光、暗角全部溶解**——游戏第一次、也是唯一一次**满屏无边框渲染**。你看了全程的"窗口",在最后一秒撤走 |

## 8. 移动端适配

| 项 | 规格 |
|---|---|
| 边框 | 瘦身版:等效 12px,顶部容纳铭牌缩写 `LS-97` |
| 桶形畸变 | 由屏幕圆角天然承担,shader 关闭 |
| 扫描线 | 保留 10%(渲染成本 0.3ms),RGB 栅格关闭 |
| 电源钮 | 屏幕左下角边缘长按 800ms 触发(OS 状态栏时钟替换演出仍按 v3 规范执行,两者不冲突——时钟是"机器外",电源钮是"机器上") |
| 开机 | 冷启动 4.0s 缩减版(保留白线展开 + 蜂鸣 + splash),暖启动 2.0s |

## 9. 性能预算

- 框定层全部效果(扫描线+栅格+畸变+辉光+呼吸)合成成本 **≤2ms GPU** @1080p [R11:Web 端按帧时间预算验收,合成路径优先 CSS/canvas overlay 与预烘焙静态层]
- `LCD MODE` 一键全关,游戏逻辑零依赖(断言:LCD MODE 下无任何游戏状态字段被读取)
- 静态层(外壳/眩光/落影)预烘焙为单张合成图,仅在会话开始与结局时重绘
- 禁止逐帧重绘外壳;扫描线为 2×2 平铺 pattern,一次 fill

## 10. CI 验收清单

1. **框内纯净**:屏幕矩形内像素与无框版本 diff = 仅效果层(扫描线/畸变/辉光),无外壳像素混入
2. **扫描线周期**:原生分辨率导出图逐行检验,周期恰为 2px
3. **开机时序**:冷启动总长 6.5±0.3s;蜂鸣落点 2.2±0.05s;暖启动 2.5±0.2s
4. **电源态机**:GV<60 全重启 / 60–79 压暗回弹且 `> no.` 全存档恰好一次 / ≥80 无反应且 Ledger 有 `power_override_denied`
5. **内存蠕变**:模拟跨日 +1K,单调递增,存档持久;真结局后可归零一次
6. **眩光曲线**:GV<96 恒 5%;96→100 线性至 0;与终端输入劫持同帧触发(时间戳断言)
7. **自发消磁**:GV≥60 间隔 30–60min 随机,触发帧个体眨眼恰 1 帧
8. **LED**:绿(<80)/琥珀(≥80);结局 B 时以光标节拍闪烁(与 ART-CORE-02 光标周期 diff <5%)
9. **辉光对象白名单**:bloom 亮度采样最高两点 = G 高光与终端光标,无第三点
10. **真结局满屏断言**:终局序列结束后,外壳/扫描线/眩光/暗角渲染调用次数 = 0

## 11. 交付顺序

```
① 静态外壳 + 扫描线/暗角 + 冷启动全程     ← 仪式感先立住
② 电源开关三态 + 消磁 + 暖启动
③ 阶段演变(失步/LED/眩光消退)+ 内存蠕变
④ 四结局框体行为 + 移动端瘦身版
```
