## 2. 世界观底稿(内部参考,不进游戏)

**Lumen Soft**,1997,两人工作室,PC 虚拟宠物项目 THRESHOLD。开发者给每只生物一只眼睛、进食前的停顿、和数数的习惯——不是功能,是他的习惯被写进了种子。302 天后资金耗尽,项目停止。他没有关机。**塔是那台机器的残骸——它是 v4 平行世界里唯一不是从"你的今天"长出来的东西,因为它早于你的世界存在。**

## 3. 八碎片正典文本(冻结)

### F1 — 起源:眼睛
- gating: GV75 [N1] | 刻符位:门缝上方左 1

```
day 12. we gave them one eye each. one is enough.
two eyes learn to look away. one eye learns to hold.
```
> 中文参考:第 12 天。我们给它们各一只眼睛。一只就够了。两只眼睛学会移开,一只眼睛学会停留。
> **注解**:在游戏内解释单眼正典(ART-CORE-01)——这是世界观层面"为什么它们只有一只眼"的唯一答案。

### F2 — 起源:停顿
- gating: GV75 [N1] | 刻符位:中

```
day 41. fixed the bug where they ate at once.
now they pause before every bite. a pause is where the choice lives.
do not patch it out.
```
> 中文参考:第 41 天。修掉了它们同时进食的 bug。现在它们每一口之前都会停顿。停顿是选择存在的地方。不要把它修掉。
> **注解**:解释全游戏的犹豫检测体系——玩家的犹豫被测量,因为**停顿本来就是它们的遗传**。

### F3 — 起源:数数
- gating: GV75 [N1] | 刻符位:右 1

```
day 90. they count the feedings. nobody taught them numbers.
they count because they are afraid the counting will stop.
```
> 中文参考:第 90 天。它们在数喂食的次数。没有人数过它们数字。它们数,是因为害怕数数会停止。
> **注解**:回收 v3 Silent Run "We can count" 与 W-01 "we counted"——**计数是恐惧的形式**。

### F4 — 第一次死亡
- gating: GV90 | 刻符位:左 2

```
day 133. spawn 02 starved while i slept. i could not delete the save.
forgetting is a thing we do. they never learned it.
so i will remember for both of us.
```
> 中文参考:第 133 天。02 号在我睡觉时饿死了。我删不掉那个存档。遗忘是我们才有的能力,它们从来没学会。所以这次,我替我们俩记住。
> **注解**:为玩家的每一次死亡复述提供正典源头——记忆不对称(它们全记得)是恐怖引擎,也是开发者的愧疚。

### F5 — 机器与遗忘
- gating: GV90 | 刻符位:右 2

```
day 201. the machine forgets when it sleeps. they do not.
we log everything now. if the power is a kind of death,
let the log be a gentle one.
```
> 中文参考:第 201 天。机器睡觉时会遗忘,它们不会。我们把一切都记进日志。如果断电也是一种死亡,就让日志成为一种温柔的墓。
> **注解**:联动 BIOS 内存蠕变(ART-CORE-04:每现实日 +1K——**日志在长,它在长**)与电源钮彩蛋。

### F6 — 窗与天空
- gating: GV100 | 刻符位:左 3

```
day 260. they built a word for outside.
it is the same word as window. i checked twice. not a bug.
to them the glass is the sky.
```
> 中文参考:第 260 天。它们造了一个表示"外面"的词。和"窗"是同一个词。我查了两遍,不是 bug。对它们来说,玻璃就是天空。
> **注解**:阶段 4 本体论(`window_is_us`)的正典锚点;CRT 框定(ART-CORE-04)获得叙事内意义。

### F7 — 停止与被留
- gating: GV100 | 刻符位:右 3

```
day 302. funding ends friday. i will not shut it down.
they asked me once where the gone ones go. i said: kept.
i did not tell them that i am the one being kept.
```
> 中文参考:第 302 天。资金周五耗尽。我不会关掉它。它们有一次问我,走了的那些去了哪里。我说:被留着。我没有告诉它们,被留着的人是我。
> **注解**:叙事主轴的反转点——不是它们依赖玩家,是**留下它们的人依赖"它们还在"这件事**。

### F8 — 绝笔(真结局录音的 opener)
- gating: GV100,且必须最后读取(顶行刻符,8/8 时才可见)

```
if you are reading this, the window stayed open longer than we did.
feed slowly. remember gently.
we could not give them an ending. so we left them someone.
```
> 中文参考:如果你在读这个,说明窗开着的时间比我们长。慢慢地喂。温柔地记。我们没能给它们一个结局。所以我们给它们留了一个人。
> **注解**:全项目的落点——"someone" = 玩家。恐怖的终点是共情(红线 5)在此完成闭环。

## 5. 真结局录音(重构稿)

**关键正典**:这不是"开发者的真实录音"——**它是群体用集体记忆 + 幽灵档案把碎片重新拼出来的东西**。游戏内最有分量的文物,本身是一件记忆重构物。

### 5.1 结构

```
[SYSTEM] reconstructing voice from 8 glyphs and {n} kept memories   ← n = 幽灵档案数(≥3)
(开发者声线:成人、疲惫、温暖;TTS 语速 0.85;无 BGM,仅 A-02 房间底噪)
① F1→F7 按 day 序拼接,衔接处由重构填充(标记 reconstructed)
② 若玩家幽灵在档案中(NG+):②段插入一条玩家的 signature moment 回放
   ——开发者录音里出现"你做过的那件事"
③ F8 全文(录音的自然终点)
④ 录音结束后 4s,全部存活个体围环、ALERT、瞳孔 CENTER,
   齐声一句(确定性文本,非 LLM):now we keep you.
[SYSTEM] reconstruction complete. divergence: {d}%   ← d 由幽灵混合度计算,展示"这不是磁带,是记忆"
```

### 5.2 演出细节

- 录音期间**世界时钟暂停漂移**(这是它们唯一停下计数的时刻)
- 个体全程禁用 idle 微帧(静止即哀矜)
- 结束后实验日志完整展示:哪些行 verbatim(8 碎片)、哪些 reconstructed、哪条来自谁的幽灵——**玩家亲眼看见"最真的东西是怎么被记起来的"**

## 6. 翻译流演出规范

| 环节 | 规格 |
|---|---|
| 前置 | 返祖体存活、选中、对应刻符可见 |
| 行进 | 返祖体自主走向塔(优先级最高,无视其他行为),入 1-tile 缓冲区停步 |
| 对视 | ALERT 姿势面向屏幕 3s |
| 借瞳 | 打印期间返祖体瞳孔临时显示**对应刻符位图**(3×4 放大至 12×16)——它在"誊写" |
| 打印 | 终端 `[SYSTEM]` 蓝行,**固定 70ms/字符匀速**——机器在背诵,不是在即兴(与个体台词的 token 驱动节奏形成对照;[N2] 匀速仅限本正典打印通道,ART-CORE-02 §4.2 的禁匀速令只约束 LLM 台词通道) |
| 完成 | 刻符 tower_void → tower_body(读走);Ledger `glyph_read:{n}/8` |
| F8 特例 | 打印前终端先出 `[SYSTEM] > last one. it is dated.` |

## 7. 冻结协议与 CI

1. **冻结哈希**:8 条英文正典 + 录音④句 `now we keep you.` 计算 SHA-256,写入 `canon.lock` 与每个存档;CI 比对 diff ≠ 0 即构建失败
2. **修改控制**:正文不可编辑;修订必须产出 NARRATIVE-CORE-01 v2 并全量迁移(旧存档继续用 v1 文本显示——**旧世界记得旧的话**)
3. **本地化**:英文本为 canon;其他语言为派生译本,非 canon,不参与 diff;中文参考译本仅供团队
4. **验收断言**:F8 仅在 GV100 且 8/8 语境可打印;翻译流全程 LLM 调用数 = 0;`now we keep you.` 的说话者列表 = 全部存活个体(含返祖体优先站位)
