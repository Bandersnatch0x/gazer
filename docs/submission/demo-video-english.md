## Copy-ready English description and transcript

```text
GAZER. You do not raise pets. You raise a model that remembers, lies, and lives on through its offspring.

A deterministic simulation controls creature physics. A language model generates dialogue and proposes events that the engine validates. The creatures remember the player's actions, share memories, and can mistake distorted memories for things they witnessed.

This edited video shows captures from a local model-connected game session. It has Mandarin narration. A complete English translation follows below. The eight bilingual text cards in the video are summaries.

The public playable build is static and has no live model backend. It runs in silent mode without generated dialogue. No account or API key is needed for that build. The repository README provides English controls and the local setup required to use your own model service.
```
